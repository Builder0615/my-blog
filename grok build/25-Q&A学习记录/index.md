# 25 Q&A 学习记录

这里专门记录你在阅读 Grok Build 过程中实际提出的问题，以及我根据源码、测试和当前快照给出的回答。没有被你问过的问题，不会因为“看起来适合这一章”就放进来。

本页只是一块持续追加的记录区。当前 Grok Build 的源码参照是 [公开提交 `ed6d543`](https://github.com/xai-org/grok-build/commit/ed6d543643628663873c5de28298e022ed634238)；以后每条回答会注明它依据的快照，避免把旧答案当成永远不变的事实。

## 记录一条问题时会保留什么

你提出问题后，我会尽量补上：

- 你的原问题和提问背景；
- 用小白能看懂的方式解释关键概念；
- 对应的源码入口、调用链或测试；
- 当前快照能确认的范围，以及仍然不确定的地方；
- 如果适合，补一个安全的本地验证方法。

问题可以很小，例如“这个 `Handle` 为什么不是 Agent 本身”，也可以是一条跨模块的疑问，例如“取消发生后工具进程、session history 和 TUI 分别怎样变化”。我不会为了凑数量，把教程正文里的知识点改写成假想提问。
