# Q&A 学习记录

这里专门记录你在阅读 Pi 过程中实际提出的问题，以及我根据 Pi 当前源码和文档给出的回答。它不是我替你预设疑问的目录，也不是把正文内容重新整理成问答形式。

## 记录方式

你提出问题后，我会根据问题的需要补充：

- 原问题和当时的阅读背景；
- 白话解释与正式类型/函数名之间的对应；
- 当前源码入口、调用链或测试依据；
- 哪些判断已经确认，哪些仍需继续核对；
- 适合初学者执行的本地验证方法。

Pi 的 main 分支变化较快。涉及源码路径的回答会尽量记录当时的链接和快照；如果答案影响正文，我会同步更新对应章节，而不是只把答案留在这里。
